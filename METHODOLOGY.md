# Gold Gap Finder — Methodology Preview

This public document explains the **high-level concept**, not the private implementation.

## Public conceptual flow

### 1. Discover
Start with a specific niche and look for recurring problems, workarounds and overlooked segments.

### 2. Verify
Separate interesting signals from stronger evidence.

### 3. Differentiate
Study existing solutions and investigate where a narrower workflow or customer segment may remain underserved.

### 4. Decide
Determine whether the evidence supports further testing, a narrower wedge, or rejection.

## The core principle

> **A market signal should start an investigation—not end one.**

The full v7 system contains the detailed implementation used to execute this methodology.
