# 🔒 Security Policy

This repository contains research methodology, documentation, and example content. It is not a software application, contains no runnable prompt for either paid product, and does not collect, store, or process any user data.

## Reporting a Concern

If you find:

- A security or privacy issue related to this repository or its linked purchase pages
- Content that appears to be leaked, pirated, or unauthorized redistribution of the Quick Scan or the full Gold Gap Finder v7 system
- A phishing page or scam impersonating this project

please report it by emailing goldgapfindersupport@gmail.com.

Please include a description of the issue, a link or screenshot if applicable, and any relevant context.

We aim to respond within a reasonable timeframe. Please do not open a public GitHub issue for security-sensitive or copyright-infringement reports — email instead.

## Scope

This policy covers this repository and its official links only. It does not cover third-party AI platforms (Claude, ChatGPT, Gemini) used to run the prompts — please refer to their own security policies for platform-level concerns.
